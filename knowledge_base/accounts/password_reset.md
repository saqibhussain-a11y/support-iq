# Password Reset

## How to reset your password

Use the "Forgot password" link on the login page. A reset link is emailed to the address on file
and expires after 1 hour.

## Support agents cannot reset passwords manually

For security, support agents cannot set or view a customer's password, and cannot send a reset
link to any email address other than the one already on file. If a customer no longer has access
to that email, they must be escalated to account security — see `account_security.md`.

## Reset link not arriving

Ask the customer to check spam/junk folders first. If it still does not arrive after 10 minutes,
confirm the email on file is spelled correctly before escalating.
